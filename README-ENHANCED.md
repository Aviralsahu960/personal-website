## 🐛 Troubleshooting

### **Background not showing?**
- Make sure `script.js` is loaded properly
- Check browser console for errors (F12)
- The geometric background requires JavaScript to be enabled

### **Tools not working?**
- Verify `script.js` is in the same folder as `index.html`
- Clear browser cache (Ctrl + F5)

### **Images not loading?**
- Ensure all image files are uploaded to Netlify
- Check file names match exactly (case-sensitive)
